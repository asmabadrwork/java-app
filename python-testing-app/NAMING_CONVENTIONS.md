# Python Naming Conventions

This project follows strict naming conventions to maintain codebase consistency in Python.

## 1. Variables and Functions
Use **snake_case** for variable names and function/method names.
- **Example**: `is_loaded`, `fetch_data()`, `user_list`

## 2. Classes
Use **PascalCase** for class names.
- **Example**: `UserProfile`, `AppConfig`, `UserUpdate`

## 3. Files and Directories
Use **snake_case** for Python modules and directory names.
- **Example**: `main.py`, `test_main.py`

## 4. Constants
Use **UPPER_SNAKE_CASE** for constant variables.
- **Example**: `MAX_RETRIES`, `DEFAULT_TIMEOUT`
